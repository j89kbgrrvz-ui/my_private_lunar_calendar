# 阴历日历订阅生成器 · 使用说明

把「庙会 / 节日」等**阴历日期**逐年换算成公历，生成可被日历 App 订阅的 `.ics` 文件。
每年对应的公历都不同，闰月也会自动处理，无需你手动计算。

---

## 一、文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 网页版编辑器（推荐），可视化增删改，双击即可打开 |
| `lunar.js` | 阴历→公历转换库（`index.html` 必须和它放在同一目录） |
| `config.json` | 命令行模式下的事件配置 |
| `generate.js` | 命令行生成器（Node.js） |
| `lunar_events.ics` | 已生成的示例日历文件（可直接订阅/导入） |
| `node_modules/` | 命令行依赖（仅 `generate.js` 需要） |

---

## 二、方式一：网页版（推荐，最易上手）

1. 保持 `index.html` 与 `lunar.js` 在**同一文件夹**。
2. 双击 `index.html` 用浏览器打开。
3. **日历设置**：填写订阅时显示的日历名称、描述、起止年份（默认 2024–2074，覆盖 50 年）。
4. **新增 / 编辑 / 删除事件**：
   - 每条事件先选**日期类型**：「阴历」（每年对应的公历不同，自动换算）或「公历」（每年同一月日重复，如元旦）。
   - 名称（必填）、分类（可选，如「庙会」）、月份、日、是否闰月（仅阴历可选）、提前提醒、颜色、备注。
   - 选「阴历」时显示「闰月」勾选框：表示如「闰二月」这类日期；该年若没有这个闰月，会自动跳过那一年；选「公历」时日上限为 31。
   - **删除**：点击「删除」后再点一次「确认删除?」即可（两步确认，无需弹窗，在内嵌/预览环境也能用）。
5. **未来日期预览**：自动显示每条事件从今年起最近若干年的公历日期，方便核对。
6. **生成并下载 `.ics`**：点击按钮即可得到 `lunar_events.ics`。
7. **导入 / 导出 JSON**：可把整套配置导出备份，或导入他人/自己改好的配置（也方便纯文本手动编辑）。
   - 数据默认自动保存在浏览器 `localStorage`，下次打开还在。

> 默认内置的 3 条「庙会」只是示例，请改成你自己的真实日期，或直接删除后新增。

## 三、方式二：命令行（适合自动化 / 定时重新生成）

适合放服务器上用定时任务（cron）定期重新生成并同步。

```bash
# 1) 编辑 config.json，修改 events 与 calendar 字段
# 2) 生成
node generate.js                 # 输出到同目录 lunar_events.ics
node generate.js config.json out.ics   # 自定义输入输出
```

`config.json` 结构：

```json
{
  "calendar": {
    "name": "阴历庙会与节日",
    "description": "由 WorkBuddy 生成的阴历日期日历订阅",
    "startYear": 2024,
    "endYear": 2074
  },
  "events": [
    {
      "id": "miaohui-yuanxiao",
      "name": "元宵庙会",
      "type": "lunar",
      "month": 1, "day": 15, "leap": false,
      "description": "农历正月十五，元宵节庙会",
      "reminderDays": 1,
      "color": "#e74c3c",
      "category": "庙会"
    }
  ]
}
```

- `month`：1–12；`day`：1–30；`leap`：`true` 表示闰月。
- `reminderDays`：0=不提醒，1/2/3/7=提前 1/2/3 天/1 周。
- `color`：事件颜色（Apple / 部分 Android 日历会显示）。

## 四、如何变成真正的「日历订阅」

「订阅」要求 `.ics` 文件固定放在一个**可被访问的网址**上，日历 App 会定期回源拉取更新。
如果只是把 `.ics` 下载到手机再导入，那是「一次性导入」，改了不会自动更新。

### 托管选项（任选其一）
1. **CloudStudio / 静态托管**：把本文件夹（含 `lunar_events.ics`）部署为静态站点，订阅地址即 `https://你的地址/lunar_events.ics`。
2. **GitHub Pages**：把文件夹推到仓库并开启 Pages，订阅地址为 `https://用户名.github.io/仓库/lunar_events.ics`。
3. **自己的服务器 / 对象存储**：上传 `lunar_events.ics`，用其公网 URL。
4. **网盘直链**：部分网盘可提供文件直链（需是 `text/calendar` 或至少可被直接下载的链接）。

### 在各 App 中添加订阅
- **iPhone / iPad 日历**：把 `.ics` 链接发给自己的微信/备忘录 → 点击链接 →「添加日历订阅」；或在「日历」App 里「添加日历账户 → 其他 → 添加订阅日历」，填入 URL。
- **Google 日历（网页）**：左侧「其他日历 ▾ → 通过 URL 添加」，粘贴 `.ics` 链接。
- **Outlook / 华为 / 小米等**：一般在「日历 → 添加账户 → 订阅日历 / 通过链接添加」中粘贴 URL。

### 更新流程
改完事件后，重新生成 `lunar_events.ics` 并**覆盖上传**到同一网址即可；日历 App 会在下次同步时自动更新（部分 App 刷新有延迟，可手动「刷新」）。

## 五、农历换算说明

- 阴历每年对应的公历日期都不同，本工具对起止年份内**每一年**都单独换算成一个日程（而非用 RRULE 近似），因此最准确。
- **闰月**：勾选闰月的事件，在「没有该闰月」的年份会自动跳过（例如 2024 年没有闰二月，则 2024 不生成）。
- **小月**：阴历有的月份只有 29 天，若你填了 30 日而该年该月恰为 29 天，则该年跳过，避免日期错位。
- 事件换算基于 `lunar-javascript` 库，支持 1900–2100 年范围。
